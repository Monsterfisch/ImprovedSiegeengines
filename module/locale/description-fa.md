# Improved Siegeengines

شیوهٔ نبرد منجنیق‌ها، تریبوشت‌ها، برج‌های محاصره و سپرهای متحرک هوش مصنوعی را بهبود می‌دهد. برج‌های محاصره می‌توانند به دیوارهای بیشتری متصل شوند و نیرو حمل کنند. برای سوار کردن پیاده‌نظام، آن‌ها را انتخاب کنید و روی برج محاصرهٔ خودی کلیک کنید. مهندسان حامل روغن می‌توانند آتش را در زمین باز گسترش دهند.
