# Improved Siegeengines

Verbessert den Kampfeinsatz von KI-Katapulten, Triboken, Belagerungstürmen und Schilden. Belagerungstürme können an mehr Mauern andocken und Truppen tragen: Wähle Fußsoldaten und klicke zum Einsteigen auf einen eigenen Belagerungsturm. Öl-Ingenieure können Feuer auf freiem Gelände ausbreiten.
