# Improved Siegeengines

Улучшает действия катапульт, требюше, осадных башен и щитов ИИ. Осадные башни могут пристыковываться к большему числу стен и перевозить войска: выберите пехоту и нажмите на дружественную осадную башню для посадки. Инженеры с маслом могут распространять огонь по открытой земле.
