# Improved Siegeengines

Javítja az MI katapultjainak, hajítógépeinek, ostromtornyainak és pajzsainak harci működését. Az ostromtornyok több falhoz dokkolhatnak és csapatokat szállíthatnak: jelölj ki gyalogosokat, és kattints egy saját ostromtoronyra a beszálláshoz. Az olajos mérnökök nyílt terepen is terjeszthetik a tüzet.
