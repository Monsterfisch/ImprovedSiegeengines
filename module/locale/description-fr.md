# Improved Siegeengines

Améliore le combat des catapultes, trébuchets, tours de siège et boucliers mobiles de l’IA. Les tours de siège peuvent s’arrimer à davantage de murs et transporter des troupes. Sélectionnez des fantassins et cliquez sur une tour de siège alliée pour les faire monter. Les ingénieurs porteurs d’huile peuvent propager le feu sur un terrain dégagé.
